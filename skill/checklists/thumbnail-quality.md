# Checklist: Thumbnail Quality

Run before declaring any thumbnail post ready. A single unchecked box means it is not ready.

## Legibility
- [ ] Viewed at roughly 120 pixels wide, and the subject still reads
- [ ] The concept survives at that size, not just the craft
- [ ] Text, if any, is readable small. If it is not, it is decoration and should go
- [ ] No fine detail is carrying meaning

## Composition
- [ ] Subject sits on a third, not dead center
- [ ] **Bottom right corner is clear.** YouTube's duration stamp lands there
- [ ] Exactly one focal point
- [ ] Every element is a main character, a supporting element, or an attention director. Anything else was deleted
- [ ] Attention directors actually point at the main character

## Color
- [ ] Subject and background separate by complementary contrast
- [ ] Checked in both light and dark mode
- [ ] The color matches the promise of the video
- [ ] Lighting is flat and bright, not moody, not backlit

## Assets
- [ ] Assets are real, sharp, and cleanly cut out
- [ ] No stills pulled off the video timeline
- [ ] No edge halos, no soft cutouts, no shadows falling the wrong way
- [ ] Any generated element that reads as fake was replaced with the real thing

## Content integrity
- [ ] **Every word read back character by character.** Models misspell confidently
- [ ] No generated numbers, charts, dashboards, or percentages left in the frame. Real screenshots composited where a number matters
- [ ] No craft instruction accidentally typeset into the image
- [ ] Nothing in the frame claims something the video does not deliver

## Package
- [ ] Thumbnail text does not repeat the title
- [ ] Exactly one curiosity lever, and the video pays it off
- [ ] The title and this thumbnail were designed as one unit
- [ ] It does not look interchangeable with the last four uploads on this channel
- [ ] It is not the current niche cliche, or it breaks it on purpose

## Score
- [ ] Scored on all four Cs
- [ ] Lowest C used as the score, not the average
- [ ] Score is 8 or above, or the one specific fix is written down
